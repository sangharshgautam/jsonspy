# JSONSpy for Visual Studio Code

JSONSpy is an enterprise JSON editing, validation, transformation, and visual schema modeling workbench for Visual Studio Code.

## Features
- **Monaco Editor & SmartFix**: Syntax highlighting and one-click automatic syntax repair.
- **Ajv Schema Validation**: Real-time Draft 2020-12 and Draft-07 JSON Schema validation.
- **Visual React Flow Schema Designer**: Interactive node-graph schema editor.
- **JSONata Query Workbench**: Real-time data mapping and transformations.

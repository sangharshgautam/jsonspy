# JSONSpy — Keyboard Shortcuts & Cheat Sheet

Quick reference for JSONSpy keyboard shortcuts across Windows, macOS, and Linux:

---

## ⌨️ Global Workspace Shortcuts

| Action | Windows / Linux | macOS |
| --- | --- | --- |
| **Open JSON File** | `Ctrl + O` | `Cmd + O` |
| **Save Active File** | `Ctrl + S` | `Cmd + S` |
| **Prettify / Format JSON** | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| **Run JSONata Query** | `Ctrl + Enter` | `Cmd + Enter` |

---

## 💡 Editor Shortcuts (Monaco)

| Action | Shortcut |

| **Find in Document** | `Ctrl + F` |
